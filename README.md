# Research Paper Intelligence System

An AI-powered RAG system for academic research.

## Features
- Upload multiple research papers in PDF format
- Extract and chunk text
- Store semantic embeddings in ChromaDB
- Ask questions across multiple papers
- Compare papers by methods, datasets, metrics, and findings
- Show source-based evidence

## Tech Stack
- Python
- Streamlit
- PyMuPDF
- Sentence Transformers
- ChromaDB
- LangChain
- OpenAI
